# so-262

Repositório da disciplina de Sistemas Operacionais (SO-262).

Aqui ficam as atividades e os exercícios desenvolvidos ao longo do semestre.

## Estrutura

- `atividades/` — atividades avaliativas, de `atividade-01` a `atividade-10`. Cada pasta tem um `README.md` com a descrição da atividade, preenchido conforme elas forem sendo definidas.
- `exercicios/` — exercícios práticos feitos em aula ou como complemento, cada um em sua própria pasta com `README.md`.
